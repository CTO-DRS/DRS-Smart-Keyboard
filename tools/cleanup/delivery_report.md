التاريخ: 2026-10-14 | القرار الحاكم: المالك — الخيار (ج) الإبقاء القانوني | المرجع: `jetpref_gate1_report.md` + `tools/cleanup/WORKLOG.md`

## 1. الملخص التنفيذي

1. المشروع وصل إلى حالته الختامية: **بنية أصلية من تطوير DRS** مع مكوّنَين مساعدَين
   مفتوحي المصدر مُندمجَين ومُصرَّح بهما إفصاحاً قانونياً كاملاً.
2. منظومة التنظيف (`tools/cleanup/`) نفّذت خمس مراحل موسومة + بوابة قياس jetpref
   + إغلاق القرار، ببروتوكول مصرفي (دفع فوري + تاغ لكل مرحلة).
3. المرحلة 1 (امتثال قانوني): 163 صفاً كانونياً + استعادة 132 ترويسة Apache-2.0
   حرفية بضمان SHA-256 للأجسام (صفر تغيير كود).
4. المرحلة 2 (قتل وقائي + إصلاح قانوني): 442 سطراً ميتاً قُتل بإثبات المترجم +
   تصحيح 5 ترويسات/تصنيفات بقرار المالك (الخيار أ حينها).
5. المرحلة 3 (`lib/color`): 3 ملفات أعيدت كتابتها كلها ≤30% (أعلاها ColorMappings 26.0%).
6. المرحلة 4 (`lib/android`): 18 ملفاً أعيدت كتابتها كلها ≤30% (أعلاها Vibrator 29.2%)
   + حالتان خاصتان بقياس فقط بقرار المالك.
7. المرحلة 5 (`lib/compose`): 22 ملفاً أعيدت كتابتها كلها ≤30% (أعلاها DrsBulletSpacer 28.6%)
   + 4 ملفات محمية لم تُمسّ + consumer فارغ بالتصميم.
8. بوابة jetpref 1: قياس API موحد (148 صفاً / 41 مستخدماً / 90 ملفاً) + تحليل معالج
   KSP (تبعية = 3 أسطر) + مقارنة ثلاثية (أ/ب/ج).
9. القرار النهائي (ج): jetpref يبقى مكوّناً مساعداً معتمداً بترويساته — أُعلن
   في THIRD_PARTY_NOTICES §2 وREADME ثنائي اللغة، وتحقق تطبيقي R8 كامل.
10. كل بوابات البناء موثقة نصياً (`BUILD SUCCESSFUL` + exit صريح + 1780/0/131)
    وخط الأساس لم يتزحزح طوال البرنامج.

## 5. المتبقي المعروف (شفافية كاملة)

1. **طبقة UI التفضيلية ما زالت jetpref بنسبة 89.2% من نقاط الاستخدام** (938/1051) —
   هذا طبيعي ومقصود بقرار (ج): المكوّن مساعد معتمد لا دَين تقني معلن.
2. **مسار الإزالة المستقبلي موثق بالكامل** في
   `tools/cleanup/measurements/jetpref_gate1_report.md` (المقارنة الثلاثية +
   تقديرات بنيوية: أ ~5,800–6,100 سطر / ب = أ − سجل يدوي + معالج) — لا يبدأ
   إلا بقرار صريح جديد من المالك.
3. **تبعية مولّد KSP = 3 أسطر** في AppPrefs.kt مع انعكاس محمي بقواعد R8
   موثقة بطبقتين + بوابة `validateReleaseR8Dex` الآلية (منها علامة
   `DrsPreferenceModelImpl`) — مستقرة ومختبَرة في release.
4. **الإفصاحان الدائمان** (`MaterialYouFlags.kt`، `SystemSettingObserver.kt`)
   يبقيان حرفية 100.0% بإفصاح قانوني دائم لا يُزال — مبرراتهما موثقة.
5. **الملفات المحمية الأربعة** (ترويسات AOSP أصليتان + أصليان DRS) محمية
   بصفر-فروق ضد `cleanup/phase4` — أي لمس مستقبلي لها يتطلب قراراً جديداً.
